- Object-Oriented Programming (classes, objects, inheritance)

## 🛠️ How to Run a Project

Each project lives in its own folder. To try one out:

```bash
git clone https://github.com/mdshameel738-web/intermidiate-python-learning.git
cd intermidiate-python-learning/day-XX
pip install -r requirements.txt   # if a requirements file is present
python main.py
```

> Note: Some folders include a `venv/` directory and starter `.zip` files from the original course exercises — the actual project code lives in the `.py` files alongside them.
